    HKI Parcels Card¶

    Track parcels from PostNL, DHL, DPD, Vinted Go, GLS, Dragonfly, Trunkrs, Cainiao, Hermes, Packeta and Correos in a single Home Assistant card.

    Automatic sensor detection, animated banners, a 4-step delivery tracker, letterbox mail with scan images, a carrier overview popup, and a complete visual editor — no YAML required.

    • Multi-carrier

      PostNL, DHL, DPD, Vinted Go, GLS, Dragonfly, Trunkrs, Cainiao, Hermes, Packeta and Correos side by side. Add the same carrier multiple times for multiple accounts or hubs.

    • Auto sensor detection

      Enter your account name — the card finds your sensors and fills in all entity IDs automatically, for both known naming schemes.

    • Carrier overview popup

      Click a carrier's logo in the combo banner to see every parcel and letter for that carrier across all tabs, expandable in place.

    • Add a parcel from the card

      Account-less carriers (GLS, Dragonfly, Trunkrs, Cainiao, Hermes, Packeta, Correos) get a "+ Add parcel" control that registers a tracking number directly.

    • Media browser

      Browse the HA media library from the editor to pick logos, banners and placeholder images.

    • Letterbox mail

      PostNL letters with scan images, split into Still to be delivered and Delivered sections.

    Quick start¶

    type: custom:hki-parcels-card
title: Parcels
carriers:
  - type: postnl_v4
    user: my_account

    Which PostNL type?

    Use postnl_v4 ("PostNL") for ha-postnl ≥ 4.0.0 (recommended). postnl ("PostNL (<v4.x)") and postnl_legacy ("PostNL (ArjenBos)") are being phased out — see Installation.

    type: custom:hki-parcels-card
title: Parcels
carriers:
  - type: dhl
    user: my_account
  - type: dpd
    user: my_account
  - type: vinted_go
    user: my_account
  - type: gls
    user: "1234ab"

    GLS has no account

    GLS tracks parcels by tracking number and postal code rather than a login — user maps to the hub's postal code.

    Vinted Go is account-based

    Vinted Go logs in with an e-mail address and a verification link (no password, no tracking-code entry) — like PostNL/DHL/DPD it has no track_parcel service, so it doesn't get the card's "+ Add parcel" control. Unlike every account-less carrier below, it tracks both incoming and outgoing parcels.

    type: custom:hki-parcels-card
title: Parcels
carriers:
  - type: dragonfly
  - type: trunkrs
    user: "1234ab"
  - type: cainiao
  - type: hermes
  - type: packeta
  - type: correos

    These six (plus GLS) are the account-less carriers — register a parcel with the "+ Add parcel" control on the card itself instead of logging into an account. See Add parcel support.

    type: custom:hki-parcels-card
title: Parcels
carriers:
  - type: postnl_v4
    user: my_account
  - type: dhl
    user: my_account
  - type: dpd
    user: my_account
  - type: vinted_go
    user: my_account
  - type: gls
    user: "1234ab"
  - type: dragonfly
  - type: trunkrs
    user: "1234ab"
  - type: cainiao
  - type: hermes
  - type: packeta
  - type: correos

    Or skip the YAML entirely — add the card via the dashboard UI and it auto-detects every installed carrier integration, pre-filling a fully configured entry for each one it finds.

    Installation Configuration

    Supported carriers¶

    All carriers below are part of the ha-parcel-integrations family — Home Assistant integrations that publish a shared canonical parcel format, which is what lets one card support all of them with the same logic.

    Carrier Integration Card type Account type
    PostNL (recommended) ha-postnl ≥ 4.0.0 postnl_v4 Account login
    PostNL (<v4.x)² ha-postnl ≤ 3.x postnl Account login
    PostNL (ArjenBos)² arjenbos/ha-postnl postnl_legacy Account login
    DHL ha-dhl-nl dhl Account login
    DPD ha-dpd dpd Account login
    Vinted Go ha-vinted-go vinted_go Account login (e-mail + verification link)
    GLS ha-gls gls Tracking number + postal code
    Dragonfly¹ ha-dragonfly dragonfly Tracking number only
    Trunkrs ha-trunkrs trunkrs Tracking number + postal code
    Cainiao ha-cainiao cainiao Tracking number only
    Hermes ha-hermes hermes Tracking number only
    Packeta ha-packeta packeta Tracking number only
    Correos ha-correos correos Tracking number only

    ¹ Created by Alwin Hummels (@HummelsTech), who also maintains it standalone at HummelsTech/ha-dragonfly — see Installation for details.

    ² Being phased out — see the deprecation notice.

    Add parcel support

    Only the account-less carriers (GLS, Dragonfly, Trunkrs, Cainiao, Hermes, Packeta, Correos) get the card's "+ Add parcel" control — PostNL, DHL, DPD and Vinted Go auto-sync every parcel tied to the logged-in account and don't expose a service to register one manually. Full explanation on the Overview page.

    Part of HKI Elements
